# Evaluation

`make eval` runs seed prompts through the deterministic provider and writes `backend/reports/latest.json` and `latest.md`. The initial rubric checks four-scene structure, presence of locked character prompts, safe output expectations and basic prose output.

## Rubrics

| Rubric | Question |
| --- | --- |
| Structure | Are Setup, Inciting Incident, Climax and Resolution all present? |
| Character consistency | Does every image prompt retain locked visual identifiers? |
| Age appropriateness | Are stakes and vocabulary suitable for the requested band? |
| Prose quality | Is the writing coherent, warm and readable aloud? |

## Adding Cases

Add a prompt and expected qualities to `backend/app/eval/dataset.json`, update evaluators when adding a measurable rubric, then run `make eval`. CI fails when the aggregate score drops below `0.80`.

An `/admin/eval` trend view is a planned managed-persistence extension; reports generated by the checked-in runner provide the current auditable baseline.
