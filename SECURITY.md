# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch and the latest tagged release.

## Private Reporting

Do not disclose vulnerabilities in a public issue. Use GitHub private vulnerability reporting when enabled, or contact the repository owner privately through their GitHub profile to establish an encrypted reporting channel. Do not include active credentials in an initial report.

## Response Expectations

Reports are acknowledged within 3 business days where possible, triaged within 7 business days, and coordinated remediation timelines are provided after severity is established.

## Sensitive Data

Never commit `.env`, OAuth secrets, Google service account JSON, Terraform state, provider tokens, raw signed URLs, or customer stories from a production instance.
